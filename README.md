1. Зайди на [railway.app](https://railway.app/) со смартфона или ПК.
2. Нажми **New Project** -> **Deploy from GitHub repo** (или загрузи файлы).
3. В настройках переменных (Variables) укажи:
   `BOT_TOKEN` = `9173034885:AAFXSXdtk5_JAYN0bRjRwFh72rKxjkNrnvM`
4. Бот мгновенно запустится и будет работать 24/7.

### Вариант 2. Render.com
1. Зайди на [render.com](https://render.com/).
2. Создай **New Background Worker**.
3. Укажи репозиторий, команду запуска: `python main.py`.
4. Бот активен круглые сутки.
